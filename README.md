# Retail Sales Data Analysis Using MySQL

## Project Overview

This project focuses on cleaning and analyzing a retail sales dataset using MySQL.

The purpose of the project is to practice SQL data cleaning, exploratory data analysis (EDA), aggregation, grouping, and sorting techniques while extracting meaningful insights from retail store data.

The analysis focuses on store performance, sales trends, foot traffic, pricing, staffing, store size, parking capacity, and yearly/monthly sales patterns.

---

## Dataset

The dataset used in this project is:

`retail_sales_demo_data.csv`

The dataset contains monthly information for different retail stores.

# 1. Data Exploration

The first step was to understand the structure and contents of the dataset.

The following SQL operations were performed:

- Viewed the complete dataset
- Created a working copy of the original table
- Checked the first 10 records
- Counted the total number of records
- Checked unique stores
- Identified the years covered by the dataset

A separate table was created for analysis so that the original dataset remained unchanged.


# 2. Data Cleaning

The dataset was checked for missing and empty values.

Missing values were checked across the major columns using IS NULL.

Examples include:
```sql
SELECT *
FROM retail_sale2
WHERE ad_spend IS NULL
OR promo_days IS NULL
OR monthly_sales IS NULL;

```
Empty values were also checked in relevant columns.

After identifying empty values in ad_spend, the affected records were removed from the working table.
```sql
DELETE
FROM retail_sale2
WHERE ad_spend = '';
```
The cleaning process helped prepare the dataset for further analysis.

# 4. Store Performance Analysis

Store-level performance was analyzed using GROUP BY, aggregation functions, and sorting.

The analysis answered questions such as:

Which 10 stores have the highest total sales?
Which 10 stores have the lowest total sales?
Which store has the highest average monthly sales?
Which store has the highest total foot traffic?
Which stores have the highest sales per employee?
Which store has the largest store size?
Which store has the highest number of parking spaces?

Example:
```
SELECT
    store_id,
    SUM(monthly_sales) AS total_sales
FROM retail_sale2
GROUP BY store_id
ORDER BY total_sales DESC
LIMIT 10;
```
Sales per employee was also calculated to compare store productivity:
```
SELECT
    store_id,
    ROUND(
        SUM(monthly_sales) / AVG(staff_count),
        2
    ) AS sales_per_employee
FROM retail_sale2
GROUP BY store_id
ORDER BY sales_per_employee DESC
LIMIT 10;
```
# 5. Time-Based Analysis

Sales performance was analyzed across different years and months.

The analysis included:

Total sales by year
Average sales by year
Year with the highest total sales
Month with the highest average sales
Month with the lowest average sales
Total sales for each year and month
Highest individual monthly sales
Lowest individual monthly sales

Example:

```
SELECT
    year,
    SUM(monthly_sales) AS total_sales
FROM retail_sale2
GROUP BY year
ORDER BY total_sales DESC;
```
Monthly sales were also calculated using both year and month:
```
SELECT
    year,
    month,
    SUM(monthly_sales) AS total_sales
FROM retail_sale2
GROUP BY year, month
ORDER BY year, month;
```
